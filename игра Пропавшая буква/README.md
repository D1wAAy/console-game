Пропавшая буква — вариант 5 (Т118)

Консольная игра: показываем слово с одной скрытой буквой (), игрок вводит
полное слово. Слова: колледж, робот, экран, тест, Астана. Попыток на слово: 2.
Победа — 4 и более угаданных слов из 5. Регистр и пробелы по краям не важны.

Запуск python game.py

Меню: 1 - Начать / 2 - Правила / 0 - Выход. После партии возврат в меню,
новый старт сбрасывает счёт. Неверный пункт меню не завершает программу
и не тратит попытки.

Функции

- main() — меню и цикл программы
- show_rules() — выводит правила
- play_game() — одна партия: состояние, ходы, итог
- read_choice(prompt, allowed) — ввод до допустимого значения, возвращает строку
- hide_letter(word, index) — копия строки с _ вместо буквы по индексу
- check_word(answer, word) — сравнение без учёта регистра и пробелов по краям, bool
- show_progress(solved, total) — выводит счёт

Проверки (все пройдено)

1. hide_letter("колледж", 4) → "колл_дж"; check_word(" КОЛЛЕДЖ ", "колледж") → True
2. Победа: 5 верных ответов → "Решено слов: 5 из 5", "Победа!"
3. Поражение: все ответы неверны → "Решено слов: 0 из 5", "Поражение."
4. Ровно 4 из 5 → "Победа!"; угаданное слово повторно не показывается
5. Ввод "9" и пустой строки в меню → сообщение об ошибке, программа продолжает
6. Две партии подряд без перезапуска → счёт второй партии сброшен (0 из 5)
